# Telegram Bot (Next.js + Telegraf + MongoDB)

## Overview

A Telegram bot built with **Telegraf**, running on **Next.js (App Router)** and deployed on **Vercel** using **webhooks**, with **MongoDB** as the database.

---

## Requirements

- Node.js 18+
- MongoDB (Atlas or local)
- Telegram Bot Token (@BotFather)
- Vercel account

---

## Environment Variables

Create a `.env` file or set variables in Vercel:

```env
BOT_TOKEN=your_telegram_bot_token
MONGOURI=mongodb+srv://your_connection_string


```
